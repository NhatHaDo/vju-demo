# VJU – Mẫu giao diện website

Bản xem thử các mẫu giao diện website Trường Đại học Việt Nhật, gồm HTML/CSS/JS tĩnh, được deploy bằng GitHub Pages.

Mở trang gốc để chọn một trong các mẫu:

- Form 1 – UniCamp
- Form 2 – Kingster
- Form 3 – Unipix
- Form 4 – Eduma

Mã nguồn sinh trang nằm ở repo dự án chính. Repo này chỉ chứa bản build để xem.
